ポーカーの役を強い順に並べた表

上にある役ほど強く、基本的には出にくい役です。例の5枚は一例で、マークや数字が違っても条件を満たせば同じ役になります。

役の定義と順番は、WSOP と PokerStars の公式ページで確認しました（出典は末尾）。

迷いやすい3つの決まり

役の順番を覚えたあとで迷うのは、次の3点です。

  • マークに強弱はありません。♠が♥より強いことはなく、マークだけが違う2つの手は引き分けです。
  • Aは大きいほうにも小さいほうにも使えます。10-J-Q-K-A は一番大きいストレート、A-2-3-4-5 は一番小さいストレート（5が一番上）です。
  • ロイヤルフラッシュは、Aが一番上のストレートフラッシュの呼び名です。別の役が1つ増えるわけではありません。

同じ役のときの勝ち負けの決め方

役が同じなら、決まった順に数字を比べます。残りの札で比べる札をキッカーと呼び、全部同じなら引き分けでポットを分けます。

同じ役のときに比べる順番
役比べる順番
ストレート／ストレートフラッシュ一番上の数字だけを比べる。A-2-3-4-5 は5が一番上（最も小さいストレート）
フォーカード4枚組の数字 → 残り1枚（キッカー）
フルハウス3枚組の数字 → 2枚組の数字
スリーカード3枚組の数字 → 残り2枚を大きい順に
ツーペア高いほうのペア → 低いほうのペア → 残り1枚
ワンペアペアの数字 → 残り3枚を大きい順に

たとえば A♠ A♥ とボードの K が1枚で、相手が A♦ A♣ とボードの Q が1枚なら、ペアは同じなので次のキッカー（K と Q）で決まり、前者の勝ちです。ホールデムでは、7枚の中から一番強い5枚を選んだうえでこの比べ方をします。

テキサスホールデムで各役が出る確率（5枚と7枚）

ホールデムは手札2枚とボード5枚の計7枚から役を作ります。5枚配りの確率をそのまま当てはめると、ホールデムの実際より役が出にくいと見積もってしまいます。

「その役になる」は、より強い役が成立していない場合だけを数えています。フルハウスの件数には、フォーカードになる組は入っていません。ストレートフラッシュはロイヤルを除いた件数です。

この表と図から読めることを3つ挙げます。

  • ロイヤルフラッシュは、5枚なら約65万回に1回、7枚なら約3万940回に1回です。約21倍出やすくなります。
  • ハイカード（役なし）は、5枚では50.1%ですが、7枚では17.4%です。ホールデムで役なしになるのは約6回に1回です。
  • 7枚で出る頻度の順番が強さの順番とずれるのは、ハイカードだけです。一番弱いのに、ワンペア（43.8%）やツーペア（23.5%）より出にくくなります。

サイトによって確率の数字が違うのはなぜか

調べると、同じ役でも数字が違う表に出会います。たいていは数え方が混ざっているのが原因です。

  • 5枚か7枚か。フロップ時点（5枚）とリバー時点（7枚）では、表の中身が別物になります。
  • 「ちょうどその役」か「その役以上」か。フラッシュ以上で数えると、ストレートフラッシュ分が足されて3.03%が3.06%になります。
  • 手札2枚がどう絡むか。「手札の2枚で作る」確率と、「7枚のどこかに作る」確率は別です。

確かめる方法は簡単で、10行を足して100%になるか見ます。この記事の表は、件数の合計が133,784,560通りになっています。

最終の役が、ボードだけで出ていた割合

ワンペアで終わった勝負の約48%は、ボードにすでにペアがあり、相手も少なくともワンペアを持っています。

ボード5枚は全員が共有します。ボードだけで役が出ているなら、相手の役もそれ以上です。この場合、勝負を分けるのは手札の数字（キッカー）になります。

たとえばスリーカードで終わったとき、約29%はボードにすでにスリーカードがあります。残りの約71%は、手札の2枚が役の種類を作っています。

ハイカードは、ボードも役なしなのでこの表から除いています。ロイヤルとストレートフラッシュは件数が少ないので合算しました。

この数字の数え方

近似やシミュレーションではなく、組み合わせを全部数えています。C言語で作った判定プログラムで、ボードの5枚の選び方2,598,960通りそれぞれに、残り47枚から手札2枚を選ぶ1,081通りを掛けた2,809,475,760通りを判定しました。

7枚の組は、ボードの切り分け方が21通りあるため重複して数えられます。役ごとの件数を21で割ると、すべて割り切れました。10行の合計は133,784,560通りで、公開されている件数表（Wikipedia「Poker probability」）の10行とも全部一致しています。

前提は、52枚のカード、ジョーカーやワイルドカードなし、ホールデム（手札2枚＋ボード5枚）の判定です。件数は役の種類ごとの数で、手札の組み合わせごとの勝率ではありません。

まとめと次の一歩

  • 強い順は、ロイヤルフラッシュからハイカードまでの10役。マークに強弱はなく、Aは大小どちらにも使えます。
  • 同じ役ならキッカーを決まった順に比べ、全部同じなら引き分けです。
  • ホールデムの確率は7枚で見ます。ハイカードは約6回に1回、ワンペアで終わる勝負の約半分はボードにペアがあります。

次の1アクションは、役を自分で判定してみることです。見るだけより、答えて確かめたほうが身につきます。ポーカー・トレーナーのクイズ（役あて）では、7枚の中から役を答えられます。
