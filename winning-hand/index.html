ホールデムで勝つ役は何？2〜9人で、勝者の最終の役がどう変わるか

全員がランダムな手札でボード5枚まで見ると、勝者の役がワンペア以下なのは、2人で43.0%、5人で19.8%、9人で9.4%です。最も多い勝ち役は、2人ならワンペア（37.1%）、3人以上ならツーペア（9人で24.6%）でした。

この記事では、ホールデムで「どの役で勝つことが多いのか」を、プレーヤーの人数別に数えました。「ワンペアで勝てるのか」「ツーペアがないと厳しいのか」に、数字で答える記事です。数字は、僕が作った判定プログラムでランダムに配った実測値で、すべて仮想チップを使った練習用の例です。

この記事は、ほかの記事とは別の問い「勝った人の役は何か」を扱います。関連する記事は次のとおりです。

  • 役の強さ一覧：1人の7枚の役の出方
  • 引き分けの確率：同点の分け合い
  • 人数別の勝率：自分の手札の勝率

先に結論です。

  • ワンペア以下で勝つ割合は、2人で43.0%、3人で31.9%、5人で19.8%、9人で9.4%です。人数が増えるほど、ワンペアでは勝ちにくくなります。
  • 最も多い勝ち役は、2人のときだけワンペア（37.1%）です。3人以上ではツーペアが最多で、2人で31.4%、9人で24.6%です。
  • ツーペア以上が勝者の過半数になるのは、2人から（57.0%）です。スリーカード以上が過半数になるのは6人から（53.3%。5人は47.8%）です。
  • ストレート以上は、9人でも49.3%で、過半数には届きません。
  • ハイカードで勝つのは、2人で5.93%、4人で0.62%、9人では0.0007%（1億回のうち717回）です。

※全員の手札がランダム・全員が最後まで残る前提の実測値です。人数は、自分を含むプレーヤーの数です。同点で分け合いになった回も、勝った役を1回と数えています。

この数字の使いどころと限界

  • 全員がランダムな手札で、最後まで残る前提です。実戦では、降りる人がいます。降りる人の手札は弱いことが多いと考えられるので、実戦の勝者の役の分布は、この表そのものにはなりません。この表は、何も選ばずに全員が残った場合の基準線です。
  • ボードに5枚目が出るまで見た場合の数字です。途中で全員が降りた回や、5枚目より前に決着した回は含まれません。
  • 勝った役の分布で、役ごとの勝率ではありません。「ワンペアで勝てる割合」は、勝者の役がワンペアだった割合のことです。
  • ストレートフラッシュ・フォーカードなどまれな役は、回数が少なく、割合の誤差が相対的に大きくなります。表の小さい値は、1億回の中の回数が少ないものです（9人のハイカードは717回）。
  • これは強さの仕組みを知るための解説で、お金を賭けて勝つための方法ではありません。実際の判断練習は、仮想チップで遊べるポーカー・トレーナーでできます。

この数字の数え方と、確かめたこと

人数ごとに、全員にランダムな2枚ずつとボード5枚を配り、7枚から最強の5枚を選ぶ判定プログラム（C言語）で全員の役を比べ、いちばん強い役のカテゴリ（ハイカード〜ストレートフラッシュ）を数えました。2〜9人の各人数で100,000,000回ずつ行いています（乱数は固定シード）。判定プログラムは、引き分けの確率の記事と同じものです。

確かめたこと。

  1. 役の出方が、全数え上げと合う。各回の1人目の7枚の役を数え、役の強さ一覧の全数え上げ（7枚の全133,784,560通り）と比べました。2〜9人の9役×8人数＝72項目のうち、71項目は標準誤差の2.3倍以内に収まりました。唯一はずれたのは7人のスリーカード（標準誤差の3.7倍）で、シードを変えて3回やり直すと、すべて標準誤差の1.8倍以内でした。偶然のずれと判断しています。
  2. 別の方式のプログラムと合う。判定を「7枚から5枚を選ぶ全21通りの総当たり」、乱数を別の方式（splitmix64）、配り方を部分シャッフルに変えた別実装で、各人数を20,000,000回ずつ数えました。勝者の役の割合は、72項目すべてで差が標準誤差の2.1倍以内（最大の差は0.021ポイント）でした。
  3. 合計が100%。各人数で、9つの役の件数の合計が100,000,000回ちょうどになります。
  4. 引き分けの確率と合う。各回の最強の手を分け合った割合は、2人で4.068%、9人で9.752%で、引き分けの確率の記事の実測（別の乱数列）と、全人数で0.003ポイント以内で一致しました。

よくある質問

勝つ役は何が多いですか？

全員がランダムな手札で最後まで残る場合、2人のときはワンペア（37.1%）、3人以上のときはツーペアが最も多い勝ち役です。9人ではツーペアが24.6%、ストレートが20.1%です。

ワンペアで勝てる割合は、人数が増えるとどうなりますか？

勝者の役がワンペアだった割合は、2人で37.1%、3人で30.0%、5人で19.6%、9人で9.4%と減っていきます。ワンペアかハイカードで勝つ割合の合計は、9人で9.4%です。

ツーペア以上が必要になるのは、何人からですか？

勝者の役がツーペア以上だった割合は、2人の時点で57.0%と過半数です。スリーカード以上が過半数になるのは6人から（53.3%）で、ストレート以上は9人でも49.3%にとどまります。

実戦でそのまま使えますか？

使えません。全員がランダムな手札で、最後まで残るという前提の実測値です。実戦では降りる人がいるので、勝者の役の分布は変わります。この表は、何も選ばずに全員が残った場合の基準線として読んでください。
