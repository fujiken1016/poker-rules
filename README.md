# ポーカー・トレーナー（poker-rules）

テキサスホールデムを全くの初心者向けに解説する学習サイト。単一HTML・依存ゼロ・静的配信のみ。

- 本番（予定）: https://rule.shoubu-lab.com （Cloudflare Pages）
- 旧URL: GitHub Pages の旧URL（移行後に案内を設置）

## 構成

| ファイル | 内容 |
|---|---|
| `index.html` | アプリ本体（ルール8章／神視点デモ6本／クイズ／CPU実戦＋コーチ／虎の巻） |
| `privacy.html` / `disclaimer.html` / `about.html` / `contact.html` | 法的ページ（広告審査要件） |
| `_legal.css` | 法的ページ共通スタイル |

## 運営方針

学習コンテンツ専用。オンラインカジノ等の賭博サービスへの誘導・広告は一切掲載しない（書籍・学習サービスのみ）。
